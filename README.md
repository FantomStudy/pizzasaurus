## Stack

Next.js 16 App Router · React 19 · TypeScript · Bun · Oxlint · Oxfmt

## Quick start

```sh
git clone https://github.com/FantomStudy/pizzasaurus.git
cd pizzasaurus
cp .env.example .env.local
bun install
bun dev
```

Open [localhost:3000](http://localhost:3000).

## Scripts

```sh
bun run build   # Build for production
bun start       # Serve the production build
bun lint        # Lint and apply fixes
bun fmt         # Format the project
```
